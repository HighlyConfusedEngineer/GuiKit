# Support

## Where to ask

Use [GitHub Discussions](https://github.com/HighlyConfusedEngineer/GuiKit/discussions)
for integration questions, design discussions, and help choosing a host
adapter. Use [Issues](https://github.com/HighlyConfusedEngineer/GuiKit/issues)
only for reproducible defects or actionable feature requests.

For a suspected security issue, follow [SECURITY.md](SECURITY.md) and do not
open a public issue.

## Information to include

Provide the GuiKit version, browser or webview engine and version, operating
system, host runtime (for example .NET or Python), and a minimal reproduction.
For bridge, chart, media, or node-editor issues, include only redacted messages
and data. Do not attach credentials, customer data, or production logs.

## Support boundaries

GuiKit maintains its documented public APIs and the latest pre-1.0 release line.
Application architecture, native-host permissions, deployment configuration,
and third-party webview defects remain the responsibility of the integrating
application. Commercial support and response-time guarantees are not currently
offered.

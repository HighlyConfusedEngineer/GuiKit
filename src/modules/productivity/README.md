# Productivity module

`@gui-template/core/productivity` contains optional dependency-free controls
for large option lists, scheduling, analytical displays, structured property
editing, file queues, notification history, and editable command profiles.

Models are DOM-independent and serializable where practical. Upload transport,
storage, authentication, and permission policy remain host-adapter concerns.
See [`docs/PRODUCTIVITY.md`](../../../docs/PRODUCTIVITY.md) for examples and
security guidance.

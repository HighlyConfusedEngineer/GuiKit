# Statusbar module

`<gui-statusbar>` is a responsive, dependency-free application status bar.
It supports top or bottom placement, sticky or fixed positioning, live keyed
updates, action items, progress, status variants, responsive priority, and
custom slotted content.

Import the complete library:

```js
import { GuiStatusbar } from "@gui-template/core";
```

Or import only this module:

```js
import {
  GuiStatusbar,
  statusbarModule,
} from "@gui-template/core/statusbar";
```

See [the statusbar guide](../../../docs/STATUSBAR.md) for configuration,
events, accessibility, and examples.
